# GRZ124 — обновлённое оформление

## 1. Файлы

Замени:
- `src/App.jsx` → содержимое из `App.jsx`
- `src/styles.css` → содержимое из `styles.css`
- `src/admin-panel.css` → содержимое из `admin-panel.css`

## 2. Папка с изображениями

Создай в папке `public`:

`public/cars/`

И положи туда 4 фотографии:

- `audi-rs.jpg`
- `land-cruiser.jpg`
- `bmw-m.jpg`
- `mercedes.jpg`

Это реальные файлы изображений, поэтому CSS/React не может создать их автоматически.

## 3. Как поменять фотографию у номера

В `FALLBACK_NUMBERS` у каждого номера есть:

`image: "/cars/audi-rs.jpg"`

Можно поставить:

`image: "/cars/land-cruiser.jpg"`

или любой другой файл из `public/cars`.

## 4. Админ-панель

В форме добавления/редактирования появился новый пункт:

`Фото: /cars/audi-rs.jpg`

Таким образом, для каждого номера можно задавать отдельное изображение.

## 5. Важный момент с Supabase

Если в таблице `numbers` ещё нет колонки `image`, запросы POST/PATCH могут вернуть ошибку.

Добавь колонку:

`image` — тип `text`

После этого изображения будут сохраняться вместе с номерами.

## 6. Если фотографии пока не добавлены

Карточки всё равно будут выглядеть корректно: появится затемнённый premium-фон. После добавления фотографий они автоматически появятся в карточках.

## 7. Главное изменение

Карточка теперь устроена так:

- автомобиль — фоном;
- затемнение поверх автомобиля;
- номерной знак — главный объект;
- VIP/Premium;
- категория;
- регион;
- цена;
- кнопка «Подробнее»;
- избранное.

Навигация на телефоне также зафиксирована внутри экрана и не должна уезжать вправо.
