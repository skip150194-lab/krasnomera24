# Красивые номера 24 — Telegram Mini App MVP

Это готовый фронтенд-прототип Mini App для каталога красивых госномеров Красноярского края.

## Что уже есть

- Главная
- Каталог
- Поиск по комбинации
- Фильтры Premium / VIP
- Карточки номеров
- Избранное через localStorage
- Мои заявки через localStorage
- Профиль
- Форма заявки
- Telegram WebApp SDK
- Адаптивный мобильный дизайн

## Запуск на компьютере

Нужен Node.js 18+.

```bash
npm install
npm run dev
```

После запуска Vite покажет локальный адрес.

## Сборка

```bash
npm run build
```

Готовые файлы будут в папке `dist`.

## Подключение к Telegram

Mini App должен быть размещён по HTTPS-адресу. В Telegram через @BotFather можно настроить Main Mini App или Menu Button и указать URL приложения.

В `index.html` уже подключён официальный Telegram Web App SDK.

Важно: сейчас это демо. Номера, цены и статусы находятся в `src/main.jsx` как тестовые данные. Для реального запуска нужно подключить backend + PostgreSQL + админку + источник актуальных номеров + корректную юридическую схему оформления.
