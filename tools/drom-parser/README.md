# Парсер красивых номеров Drom для GRZ124

Парсер проверяет текст описаний активных объявлений о продаже автомобилей в Красноярском крае и сохраняет объявления с красивыми госномерами регионов 24 и 124.

## Расход кредитов

Ноль. Скрипт не использует ChatGPT API, OCR, нейросети или платные сервисы.

## Как установить на MacBook

1. Скачайте репозиторий: кнопка Code → Download ZIP.
2. Распакуйте архив.
3. Откройте папку tools/drom-parser.
4. Один раз откройте Терминал в этой папке и выполните:

   chmod +x "Запустить парсер.command"

5. Дважды нажмите на файл «Запустить парсер.command».
6. Если macOS заблокирует первый запуск: правый клик → Открыть → Открыть.

Первый запуск установит Playwright и Chromium. Далее установка повторяться не будет.

## Результаты

Результат появляется рядом со скриптом в файле beautiful_numbers.csv. CSV открывается в Numbers и Excel.

Проверенные ссылки хранятся в checked_ads.json. Повторный запуск пропускает их и проверяет только новые объявления.

## Какие номера считаются красивыми

- первая сотня: 001–099;
- одинаковые цифры: 111, 555, 777;
- зеркала: 121, 505, 898;
- последовательности: 123, 456, 789;
- сотни: 100, 500, 900;
- одинаковые и зеркальные буквы.

## Важно

Скрипт работает только с публичным текстом описания. Фотографии и телефоны не анализируются. Изображения, видео и шрифты блокируются для экономии трафика.

При появлении проверки Drom пройдите её вручную в открытом окне браузера. Скрипт не обходит CAPTCHA и не должен использоваться для создания чрезмерной нагрузки на сайт.
